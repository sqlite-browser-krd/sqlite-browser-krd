About the app

SQLite Browser lets you open, create and edit SQLite databases directly on your phone. No account, no ads tracking, no runtime permissions – your files stay with you.

Browse & edit data

View tables, search and filter rows, and add new rows with a simple form.

Visual structure editor

Create tables, alter tables and manage indexes without writing SQL.

SQL console

Run your own SQL queries whenever you need full control.

Import & export

Import databases, export tables to CSV, or save a copy of the whole .db file.

Take a look inside

Clean, simple screens designed for working with databases on a phone.

1

All your databases in one place

Tap a database to open it, export a copy, or delete it. Create a new database or import an existing one with a single tap.

2

Create a database instantly

Name your database and optionally paste SQL to create tables and insert data right away.

3

Build tables visually

Add columns, choose types, and set primary key and NOT NULL with checkboxes – or switch to SQL if you prefer.

4

Add rows in seconds

A simple form is generated from your table columns. Empty fields use the column default, and you can type NULL for a NULL value.

5

Import & export anything

Export a table to CSV, import CSV data, or export the whole database as a .db file.

6

Light & dark theme

Switch between light and dark themes to work comfortably any time of day.
